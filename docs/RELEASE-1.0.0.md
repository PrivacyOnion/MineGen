# MineGen 1.0.0

Standalone distribution of the MineGen terrain engine for **Paper 1.21.11 / Java 21**.

- Automatic creation and loading of a dedicated world.
- Configurable seed, name, structures, difficulty and first-join teleportation.
- `/minegen status`, `/minegen tp` and `/mg` alias.
- Teleport permission defaults to server operators.

Download **MineGen-1.0.0.jar** and place it in your server's `plugins/` folder while the server is stopped. Restart, then use `/minegen tp` as an operator. No client mod or extra plugin is required.

The ZIP includes the same JAR, installation notes, example configuration, historical validation report, credits and SHA-256 checksum. The tested JAR is published unchanged; no new server test was performed for this documentation publication. See VALIDATION.txt for the September 12 test scope and limitations.

Compatibility is limited to Paper 1.21.11. Back up worlds before updating and use a full restart.
